=== SLIDE 2 ===
  * Project Overview
  * CyberMind-AI
  * 2
  * CyberMind AI is an enterprise-grade AI-powered Cyber Threat Intelligence (CTI) and Malware Analysis Platform designed to consolidate multi-vector telemetry into a single pane of glass. The system integrates rule-based heuristics, 4 supervised machine learning classifiers, and generative AI explanations to produce a unified 0–100 cyber risk score and automated executive mitigation reports.
  * 01 | 10 Specialized Scanners
  * MODULAR MULTI-VECTOR ENGINES
  * •  Full-spectrum threat surface coverage across Web, Network, Files, and Endpoints.
  * •  Dedicated modules for URL, Website, Domain, Email, IP, Phone, File/PE, and QR.
  * •  Universal Auto-Scanner with intelligent input type inference & auto-dispatch.
  * 02 | 13 External APIs & 30+ Services
  * AGGREGATED THREAT INTELLIGENCE FEEDS
  * •  Real-time enrichment via 13 APIs: VirusTotal, AbuseIPDB, Google Safe Browsing, Groq, Veriphone, Numverify, Abstract, IPinfo, IPQS, VerificarEmails.
  * •  IPinfo & IPQS for geolocation, ASN, proxy, and VPN/Tor exit-node detection.
  * •  Resilient services layer with asynchronous timeouts and heuristic fallback.
  * 03 | Machine Learning
  * SUPERVISED THREAT CLASSIFIERS
  * •  4 Scikit-Learn Random Forest models trained on 242,341 verified security samples.
  * •  50 lexical and structural URL features extracted in real time for phishing.
  * •  PE header anomaly detection, section entropy, and hex signature analysis.
  * 04 | Generative AI
  * GROQ LLAMA-3 70B SYNTHESIS
  * •  Translates complex JSON telemetry into concise 3-sentence executive summaries.
  * •  Tailored defensive recommendations for both analysts and executive leaders.
  * •  Rule-based advisory fallback ensures continuous intelligence even offline.

  * ✔ Provider-Agnostic Services Layer
External APIs are queried exclusively through modular adapters in services/, ensuring core scanner logic remains vendor-independent.
  * ✔ Hybrid Machine Learning + Generative AI
Combines high-speed supervised Random Forest models for anomaly classification with Groq Llama-3 70B for explainable contextual intelligence.
  * ✔ Centralized Telemetry & Indexing
Every scan event, API response latency, and detection flag is logged in SQLite with 11 performance indexes ensuring sub-second lookups.
  * ✔ Automated Offline Fallbacks
Every external service dependency implements graceful local heuristic fallbacks to guarantee platform uptime during network outages.

=== SLIDE 8 ===
  * Risk Engine & AI Explanation
  * CyberMind-AI
  * 8
  * UNIFIED 0–100 RISK ENGINE (modules/risk_engine.py)
  * Multi-Factor Mathematical Formulation:
  Risk Score = (w1 · API_Score) + (w2 · ML_Prob) + (w3 · Heuristics)
  Where w1=0.45, w2=0.35, w3=0.20 (dynamically weighted).
  * Critical Override Logic:
 If VirusTotal engine flags > 5 OR Google Safe Browsing triggers, the score is automatically escalated to 90–100 (Critical), overriding benign weights.
  * 5 Standardized Severity Bands:
  * • 🟢 SAFE (0–20): Clean reputation, valid SSL, zero engine blacklist hits.
  * • 🔵 LOW (21–40): Minor misconfigurations (missing CSP headers, new domain).
  * • 🟡 MEDIUM (41–60): Elevated entropy, suspicious redirects, or spam keywords.
  * • 🟠 HIGH (61–80): Multiple threat indicators, high abuse confidence score.
  * • 🔴 CRITICAL (81–100): Active malware distribution, verified phishing, known C2 IP.
  * GROQ LLAMA-3 GENERATIVE AI EXPLANATION ENGINE
  * ✔ Contextual Threat Translation
Synthesizes multi-page JSON payloads from VirusTotal, AbuseIPDB, and ML models into a clean 3-sentence executive summary that non-technical managers can instantly comprehend.
  * ✔ Actionable Remediation Directives
Generates role-specific mitigation recommendations:
• For SOC Analysts: Specific iptables block rules, DNS sinkhole targets, and hash blacklist values.
• For Leadership: Business impact, user credential revoking advice, and policy adjustments.
  * ✔ Low-Latency Inference via Groq Cloud
Integrates Groq Llama-3 70B API via modules/ai_assistant.py, streaming high-speed reasoning tokens in under 1.2 seconds.
  * ✔ Resilient Offline Heuristic Engine
Includes an embedded deterministic template engine that automatically provides rule-based remediation when GROQ_API_KEY is not set or network is disconnected.
